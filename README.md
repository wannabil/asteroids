# 🪐 Asteroids Game

Simple Asteroids game

---

## 🚀 Getting Started

### 1. Clone this repo

```bash
git clone https://github.com/your-username/asteroids.git
cd asteroids
```

### 2. Set up a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install pygame==2.6.1
```

### 4. Launch the game

```bash
python3 main.py
```

---

## 🎮 Controls

- `W` – Forward 
- `A` – Turn left
- `S` – Reverse   
- `D` – Turn right  

---

## ❌ How to Exit

The game ends **when you get hit by an asteroid**. There's no quit button—go out with a bang 💥

---

## 🛠 Requirements

- Python 3.7+
- Pygame 2.6.1
